## 全局改名：一事 → 一账

用户要求应用名改为「一账」，并把工作空间文件夹一起改名。选择**全量改名**（用户确认）：

- App 显示名：`INFOPLIST_KEY_CFBundleDisplayName = 一账`（Debug/Release 两处）
- 工程：`YiShi.xcodeproj` → `YiZhang.xcodeproj`，目标/模块 `YiShi` → `YiZhang`，测试目标 `YiShiTests` → `YiZhangTests`
- 目录：`YiShi/` → `YiZhang/`，`YiShiTests/` → `YiZhangTests/`，`YiShiApp.swift` → `YiZhangApp.swift`，scheme `YiZhang.xcscheme`
- Bundle ID：`com.xiaoban.yishi` → `com.xiaoban.yizhang`（测试包 `…yizhang.tests`）
- 运行期标识随之改：通知前缀 `yizhang.sub.due|renew|todo.due|sub.pre`、`AppLockService.enabledKey = yizhang.appLock.enabled`、导出文件名 `一账-账目-yyyyMMdd.csv`、JSON `"app": "一账"`、DEBUG 启动参数 `-YIZHANG_*`、`yizhang-perf.log`
- 文案：锁定页「一账已锁定」、设置页隐私说明「一账」不需要注册账号
- 文档：`docs/01-PRD.md`、`docs/02-ARCHITECTURE.md` 的品牌名与标识全部同步（PRD §1.3 主线段落改写为「每一件『事』，最后都落成一笔『账』」）
- 文件头注释：`//  一账 / Core/...`、`//  一账Tests / ...`

**替换时的坑（重要）**：不能用「一事 → 一账」模糊替换，会把「同一事务」变成「同一账务」、「一件事」变成「一账件」、「这一事实」变成「这一账实」。必须按精确形态（文件头、`「一事」`、`一事-账目-`、`"app": "一事"`、`一事已锁定`）逐类替换；英文名同理按 `YiShi`/`yishi`/`YISHI` 三种大小写分别处理。

**兼容性影响**（数据都是开发期，可接受）：

- UserDefaults 键改名 → 已有的 App 锁开关会复位为关闭
- 通知标识前缀改名 → 旧前缀排队的通知成为孤儿（随旧包卸载一起清掉）
